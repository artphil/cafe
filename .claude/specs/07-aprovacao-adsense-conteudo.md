# Spec 07: Conteúdo para aprovação no AdSense

**Status:** novo

## Problema
O Google reprovou o site por conteúdo de baixo valor.

## Tarefas
- [ ] Remover placeholders de `src/data/cafes.js` (`[conteúdo aqui]`, `[endereço aqui]`, `site: "#"`) e preencher dados reais das 4 cafeterias
- [ ] Escrever 15 a 25 artigos/páginas originais com ~600+ palavras, autoria e fotos (temas no spec 02)
- [ ] Enriquecer a home com texto editorial, não só links
- [ ] Conferir anúncios: sem anúncios em páginas pobres
- [ ] Reenviar para análise 2 a 4 semanas após publicar

## Critério de pronto
Nenhuma página com texto placeholder; cada página com conteúdo próprio e útil.
